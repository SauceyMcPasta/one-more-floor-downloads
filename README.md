# One More Floor: Tiny Criminal

Standalone third-person raccoon stealth heist for Windows 10/11 x64.

## Download and play

[Download OneMoreFloorLauncher.exe](https://github.com/SauceyMcPasta/one-more-floor-downloads/releases/latest/download/OneMoreFloorLauncher.exe)

1. Download the launcher and keep it somewhere convenient.
2. Run `OneMoreFloorLauncher.exe` and click **Install**.
3. Click **Play** once installation finishes.

The launcher automatically checks for new game releases. Click **Update** when one is available. Installed games can be played offline. **Repair** downloads a fresh verified copy; saved progress is kept separately.

[Patch notes and all downloads](https://github.com/SauceyMcPasta/one-more-floor-downloads/releases)

## Controls

- WASD: move; mouse: camera; Space: jump.
- Left click: combo attack; right click: collect/interact.
- Shift: sprint; Ctrl: moving crouch; E: squeak; Z: flashlight.
- Controller: X/Square attacks; B/Circle interacts; A/Cross jumps; Y/Triangle squeaks; RB/R1 flashlight; RT/R2 sprint; LT/L2 crouch.

## About this build

This is an early prototype with procedural art. Windows executables are unsigned. Game saves remain at `%APPDATA%\Godot\app_userdata\One More Floor`. Launcher state and installations live at `%APPDATA%\OneMoreFloorLauncher`.

This repository contains player downloads and patch notes. Game source is kept separately. No account or subscription is needed to download and play.
